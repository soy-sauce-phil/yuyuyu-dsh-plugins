# DSH 总入口

把侧栏所有小部件收进一个入口。侧栏底部只留一个小图标，点开是一个九宫格，点哪个就打开哪个。

## 功能

- 自动列出所有已安装的侧栏小部件（包括小说和贴吧），按快捷键顺序排列
- 每个格子上显示小部件名称、快捷键，以及它自己的提醒数字（比如 RSS 未读数、今日刷题进度、下班倒计时）
- 点格子直接打开对应小部件，再点右上角 ⌄ 收起
- 想恢复成一排小图标：在总入口里取消勾选「收进总入口」。这个选择会被记住
- 总入口自己不占用快捷键；各小部件原来的快捷键照常可用，例如 `⌥⇧S` 仍然展开 / 收起 RSS

## 快捷键（macOS，Windows / Linux 用 Alt+Shift）

| 快捷键 | 作用 |
|---|---|---|
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

总入口没有自己的快捷键，点侧栏的图标展开，点格子打开对应小部件。

## 安装

在插件市场里安装，或在 DSH 插件管理中安装：

```
git+https://github.com/soy-sauce-phil/yuyuyu-dsh-plugins.git#main&path:/dsh-dockhub
```

安装后刷新页面即可。

## 说明

- 总入口只是把图标收起来，其他小部件仍然各自安装、各自工作。卸载总入口后，它们会重新显示自己的小图标。
- 收起成一个图标后，未读数、下班倒计时之类的数字要点开总入口才看得到。如果你更习惯直接看到这些数字，可以取消「收进总入口」。
