# 侧栏小说 · dsh-novel-reader

在 DeepSeek Harness（DSH）左侧栏、工作区列表下方的小窗口里看小说，兼容「阅读（Legado）」格式的书源。

## 功能

- **书架**：记录每本书的阅读进度，支持目录、上一章 / 下一章、调节字号。
- **本地 TXT**：导入时自动识别章节。
- **在线书源**：
  - 兼容 Legado 书源的 CSS、JSOUP、JSONPath 规则和 JS 脚本。
  - 书源 JS 在隔离的 QuickJS（WebAssembly）沙箱中运行，有超时和内存限制。
  - 网络请求只允许访问公网的 http(s) 地址，访问本机和内网的请求都会被拦截。
- **导入书源**：粘贴书源 JSON、填订阅链接，或从文件导入。书源只保存在你本机的浏览器存储里。
- **搜索**：多个书源并发搜索，结果逐步显示，可随时停止。
- **小部件**：可以收起成一个小图标；和本仓库的其他侧栏插件互斥展开，同一时间只展开一个。

内置的书源只有一个示例：[古登堡计划 Project Gutenberg](https://www.gutenberg.org/) 的公版书。**本仓库不提供、也不推荐任何第三方书源**，请自行选择合法的内容来源。

## 快捷键（macOS）

| 快捷键 | 作用 |
|---|---|
| `⌥⇧N` | 展开 / 收起小说 |
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

在 Windows / Linux 上用 `Alt+Shift+相应字母`。

## 已知限制

以下书源用不了：
- 需要 WebView、验证码、登录才能用的书源。
- 使用 XPath 规则的书源。
- 用到 `JavaImporter`、读写文件、字体反爬的书源。
