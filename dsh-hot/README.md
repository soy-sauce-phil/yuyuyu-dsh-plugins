# DSH 热榜

在 DSH 左侧栏看各平台热榜，点击条目在浏览器中打开。

## 功能

- 知乎、百度、B 站、抖音、今日头条、掘金、Hacker News、GitHub 热门（V2EX 需要网络能访问）
- 可选显示哪些榜单、是否显示摘要和图片
- 看过的条目会变灰，可清除
- 再次点击当前标签即刷新

## 快捷键（macOS，Windows / Linux 用 Alt+Shift）

| 快捷键 | 作用 |
|---|---|
| `⌥⇧B` | 展开 / 收起热榜 |
| `⌥⇧R` | 刷新当前榜单（卡片展开时） |
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

## 安装

在插件市场里安装，或在 DSH 插件管理中安装：

```
git+https://github.com/soy-sauce-phil/yuyuyu-dsh-plugins.git#main&path:/dsh-hot
```

安装后刷新页面。这个插件有后台代码，第一次安装或更新后需要重启 DSH（⌘Q 后重新打开）。

## 说明

- 数据来自各平台的公开网页接口，接口变化时个别榜单可能失效。
- 结果在后台缓存 60 秒。
