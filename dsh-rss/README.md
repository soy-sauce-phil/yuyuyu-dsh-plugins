# DSH RSS 阅读器

在 DSH 左侧栏订阅和阅读 RSS / Atom / JSON Feed，可以收起成显示未读数的小图标。

## 功能

- 内置少数派、IT之家、阮一峰的网络日志、小众软件、Solidot 五个订阅，可以删除
- 输入网站首页（如 `sspai.com`）会自动发现订阅地址
- 未读计数、只看未读、一键全读、上一篇 / 下一篇
- 在卡片里阅读正文，图片可点开大图；也可以在浏览器打开原文
- OPML 导入（文件或粘贴）和导出
- 自动刷新间隔可选 15 分钟到 3 小时

## 快捷键（macOS，Windows / Linux 用 Alt+Shift）

| 快捷键 | 作用 |
|---|---|
| `⌥⇧S` | 展开 / 收起 RSS |
| `⌥⇧R` | 刷新全部订阅（卡片展开时） |
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

## 安装

在插件市场里安装，或在 DSH 插件管理中安装：

```
git+https://github.com/soy-sauce-phil/yuyuyu-dsh-plugins.git#main&path:/dsh-rss
```

安装后刷新页面。这个插件有后台代码，第一次安装或更新后需要重启 DSH（⌘Q 后重新打开）。

## 说明

- 订阅由 DSH 后台抓取，会拒绝访问本机和内网地址。
- 正文会去掉脚本、样式和内嵌框架，只保留基本排版。
- 订阅列表、已读状态保存在本机浏览器；正文只在内存里，刷新页面后会重新抓取。
