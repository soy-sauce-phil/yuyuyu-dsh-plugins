# DSH 盯盘

在 DSH 左侧栏看 A 股、港股、美股行情和基金净值，收起时小图标显示你关注的涨跌幅。

## 功能

- 默认关注上证、深成、创业板、恒生、纳斯达克，可增删和排序
- 按名称、代码或拼音搜索股票、指数和基金
- 填写持仓股数和成本后，显示今日盈亏、持仓盈亏和市值（只计人民币资产）
- 小图标可以显示某一只的涨跌幅，或今日总盈亏
- “藏金额”隐藏所有金额；可切换红涨绿跌 / 绿涨红跌
- 卡片展开且有市场开盘时每 5 秒刷新，否则降低频率

## 快捷键（macOS，Windows / Linux 用 Alt+Shift）

| 快捷键 | 作用 |
|---|---|
| `⌥⇧G` | 展开 / 收起盯盘 |
| `⌥⇧R` | 立即刷新（卡片展开时） |
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

## 安装

在插件市场里安装，或在 DSH 插件管理中安装：

```
git+https://github.com/soy-sauce-phil/yuyuyu-dsh-plugins.git#main&path:/dsh-stock
```

安装后刷新页面。这个插件有后台代码，第一次安装或更新后需要重启 DSH（⌘Q 后重新打开）。

## 说明

- 行情来自腾讯财经公开接口，基金净值来自天天基金公开接口，可能有延迟，仅供参考，不构成投资建议。
- 基金盘中估值接口目前已不提供数据，显示的是最近公布的净值。
- 关注列表和持仓只保存在本机浏览器。
