# 侧栏贴吧 · dsh-tieba

在 DeepSeek Harness（DSH）左侧栏、工作区列表下方，用一个小窗口**只读浏览**百度贴吧。

## 功能

- **推荐**：贴吧 App 首页的推荐流，登录后是个性化推荐；滚到底自动加载更多，可刷新换一批。
- **进吧**：输入吧名时联想；显示最近访问的吧；登录后显示「我关注的吧」。
- **吧内**：按最新回复、最新发布排序，或只看精品；显示置顶和精品标记，以及帖子图片缩略图。
- **看帖**：支持只看楼主、翻页、调节字号；可展开楼中楼；点击图片在应用内大图查看，可用 ← → 切换。
- **刷新**：卡片顶部的 🔄 按钮，或按 `⌥⇧R`。
- **回复**：插件本身不发帖。点「回复」或「回复帖子」会在浏览器中打开对应楼层，在网页上回复。
- **小部件**：可以收起成一个小图标；和本仓库的其他侧栏插件互斥展开，同一时间只展开一个。

## 快捷键（macOS）

| 快捷键 | 作用 |
|---|---|
| `⌥⇧T` | 展开 / 收起贴吧 |
| `⌥⇧R` | 刷新当前页面（贴吧展开时） |
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

在 Windows / Linux 上用 `Alt+Shift+相应字母`。

## 登录（可选）

不登录也能浏览公开内容。登录后才能看到「我关注的吧」和个性化推荐，登录方式是粘贴 `BDUSS`：

1. 用浏览器登录 tieba.baidu.com。
2. 打开开发者工具，进入 Application（应用）→ Cookies → `https://tieba.baidu.com`。
3. 复制 `BDUSS` 的值，粘贴到插件的「账号」页。也可以把整段 Cookie 粘进去。

> ⚠️ **BDUSS 等同于你的百度账号登录凭证**，别人拿到就能直接登录你的账号。不要把它发给任何人，也不要提交到 Git 仓库。
> 插件把它保存在本机 `~/.dsh-tieba/auth.json`，文件权限为仅本人可读。BDUSS 只会发送给百度，不会回传到页面。在账号页点「退出登录」即可删除该文件。
