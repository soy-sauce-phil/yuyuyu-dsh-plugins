# DSH 小游戏

在 DSH 左侧栏玩 2048、扫雷、数独，完全离线，进度自动保存。

## 功能

- 2048：方向键 / WASD / 拖动，可撤销一步，记录最高分
- 扫雷：初级 / 中级 / 高级，第一下不会踩雷，右键插旗，点数字快速翻开周围，记录最快用时
- 数独：简单 / 中等 / 困难，保证唯一解；笔记模式、提示、高亮同数字和同行列宫，记录最快用时

## 快捷键（macOS，Windows / Linux 用 Alt+Shift）

| 快捷键 | 作用 |
|---|---|
| `⌥⇧M` | 展开 / 收起小游戏 |
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

## 安装

在插件市场里安装，或在 DSH 插件管理中安装：

```
git+https://github.com/soy-sauce-phil/yuyuyu-dsh-plugins.git#main&path:/dsh-games
```

安装后刷新页面。

## 说明

- 游戏按键只在鼠标停在卡片上或卡片获得焦点时生效，不会影响输入框打字。
- 收起卡片或刷新页面后，当前局面会保留。
