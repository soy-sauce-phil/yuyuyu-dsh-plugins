# DSH 摸鱼助手

下班倒计时、摸鱼和健康提醒，以及一键“假装工作”。

## 功能

- 下班倒计时：收起时小图标显示剩余时间，也可以改为今日进度或今日已赚
- 支持午休时间和自定义工作日；填月薪后显示“今日已赚”（默认不显示）
- 周末、发薪日、元旦 / 春节 / 清明 / 劳动节 / 端午 / 中秋 / 国庆倒计时，可添加自己的倒计时
- 喝水、起身活动、护眼 20-20-20、摸鱼提醒，间隔可调，默认只在上班时间提醒，可选系统通知
- **工时统计**：自动记录每天实际上下班时间（当天第一次 / 最后一次在 DSH 里操作），也可以手动「下班打卡」或直接改时间；统计本周、本月、上月的总工时、日均和加班，休息日工时全算加班，可导出 CSV
- **低调模式**：可以给这个小部件改个名字（比如「日程」），并让收起时的图标不显示倒计时数字；打开后提醒文字也会换成普通的日志式文字
- 假装工作：把所有侧栏小部件（包括九宫格里的文字标签）（包括小说和贴吧）伪装成代码编辑器的样子，图片会隐藏，标题换成文件名

## 快捷键（macOS，Windows / Linux 用 Alt+Shift）

| 快捷键 | 作用 |
|---|---|
| `⌥⇧Y` | 展开 / 收起摸鱼助手 |
| `⌥⇧D` | 开启 / 关闭假装工作 |
| `⌥⇧H` | 隐藏 / 显示所有侧栏小部件 |

## 安装

在插件市场里安装，或在 DSH 插件管理中安装：

```
git+https://github.com/soy-sauce-phil/yuyuyu-dsh-plugins.git#main&path:/dsh-moyu
```

安装后刷新页面。

## 说明

- 节日倒计时按节日当天计算，实际放假和调休以国务院通知为准。
- 伪装模式下提醒文字也会变成像编译日志的样子，并且不发系统通知。
- 工资等设置只保存在本机浏览器。
